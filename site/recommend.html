What else matters.

The questionnaire covers what the catalog knows well enough to score. Everything below is what we still want to cover.

01

Economics

Free tier, minimum spend, billing unit, fixed vs metered billing, idle cost, egress, storage, build minutes, support cost, commitments, credits, and price predictability.

02

Runtime fit

Git, Docker, Compose, VMs, Kubernetes, functions, WebAssembly, supported languages, process duration, cold starts, background workers, cron, GPUs, and sandboxing.

03

Network and state

HTTP, WebSockets, TCP/UDP, Anycast, private networking, static IPs, service discovery, volumes, managed databases, object storage, backup, replication, and disaster recovery.

04

Developer workflow

Time to first deploy, CLI quality, local parity, build system, rollbacks, previews, monorepos, environments, secrets, logs, metrics, tracing, shell access, and API or IaC coverage.

05

Operations

Scale-to-zero, autoscaling controls, health checks, zero-downtime deploys, maintenance, SLOs, status history, support responsiveness, quotas, incident tooling, and observability retention.

06

Governance

Regions, data residency, SOC 2, ISO 27001, HIPAA, PCI, GDPR, SSO, SCIM, RBAC, audit logs, customer-managed keys, private connectivity, and enterprise contracts.

07

Strategic fit

Open source, portability, BYOC, cloud ownership, provider maturity, acquisition risk, roadmap stability, export paths, standard protocols, ecosystem depth, and lock-in.

08

Workload behavior

Steady vs bursty traffic, latency sensitivity, global distribution, compute/memory ratio, CPU architecture, GPU type, local-disk need, noisy-neighbor tolerance, and regulatory boundaries.
